## 条件 D 兼容性验证（Codex + DeepSeek-V4）

**日期**: 2026-08-27  
**Harness**: OpenAI Codex CLI
**模型**: DeepSeek-V4 (通过 DeepSeek 官方 API 接入，模型名 deepseek-chat)

**验证方法**:
1. 修改 Codex CLI 配置文件 `~/.codex/config.toml`
2. 新增 [model_providers.deepseek] 区块：
   - base_url = "https://api.deepseek.com/v1"
   - env_key = "DEEPSEEK_API_KEY"
   - wire_api = "responses"
3. 切换默认模型：`model = "deepseek-chat"`，`model_provider = "deepseek"`
4. 设置环境变量：`export DEEPSEEK_API_KEY="sk-..."`
5. 启动 Codex：`codex "你好，请用一句话解释什么是情感分析"`

**验证结果**:
- ✅ Codex CLI 正常启动，状态栏显示 `deepseek-chat medium`
- ✅ 中文 prompt 正常接收，中文回复完整
- ✅ 无连接错误或认证错误
- ⚠️ 提示 Model metadata fallback（不影响核心功能）

**关键发现**:
- Codex CLI 支持通过 config.toml 自定义 model provider，非硬编码 OpenAI
- DeepSeek API 兼容 OpenAI 的 responses 接口格式
- 可通过 `sed` 命令快速在 ofoxai 和 deepseek 之间切换 provider

**结论**: 条件 D（Codex + V4）正式可行。
